# ҮҮИ орлуулгын бүртгэл

Excel шиг гараар бөглөнө.

1. Салбар, тайлант сараа сонгоно.
2. Бүтээгдэхүүн, ААНБ, өмнөх үнээ нүдэнд бичнэ.
3. Орлуулгын аргыг сонгоно, өөрчлөлтийн хувиа оруулна.
4. **Тайлант үнэ** = өмнөх үнэ × (1 + хувь/100) автоматаар гарна.
5. Хадгална. Excel тайлан татна. Дараа сард зүүн талын **түүх**ээс харна. «Өмнөх сарын түүхээс татах» дарвал өмнөх сарын тайлант үнэ шинэ сарын өмнөх үнэ болно.
