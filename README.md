# ҮҮИ орлуулга — мэргэжилтний веб

Үйлдвэрлэгчийн үнийн индексийн **2026 оны аргачлал**-д тулгуурласан ажлын хэрэгсэл. Бүх хамрах салбар (B уул уурхай, C боловсруулах, D цахилгаан, E ус, H тээвэр, I буудал/хоол, J мэдээлэл холбоо) дээр орлуулгын дарааллыг санал болгож, тооцоо хийж, баримт үлдээнэ.

Албан ёсны нийтлэлийн тоо **биш**. Жишээ өгөгдөлтэй сургалт, ажлын загвар.

## Асаах

Файлыг шууд нээнэ:

```
index.html
```

эсвэл:

```
run.bat
```

GitHub Pages: энэ репогийн `main` дээр `index.html` байгаа тул Settings → Pages → Deploy from branch.

## Юу хийдэг вэ

1. **Ажлын жагсаалт** — алгассан үнэ, хөлдүү үнэ, чанар/багц, хэмжих нэгж, хэт хазайлт.
2. **Орлуулга** — аргачлалын 1–6 дараалал:
   - харьцуулах боломжтой орлуулга
   - давхцах үе
   - зорилтот дунджаар орлуулах
   - ерөнхий дунджаар орлуулах
   - тоо хэмжээ / металл агуулга
   - өмнөх үеийн үнийг хадгалах (сүүлийн сонголт, тайлбар заавал)
3. **Индекс** — бүлэгт Жевонс, салбар/ерөнхийд Ласпейрес.
4. **Баримт** — хэн, хэзээ, ямар арга, ямар үнэ.

Мэргэжилтэн «ижил чанартай юу» гэдгийг батална. Програм шийдвэрийг бүрэн автомат болгодоггүй.

## Файл

| Файл | Үүрэг |
|------|--------|
| `engine.js` | Орлуулга, Жевонс, Ласпейрес |
| `data.js` | Бүх салбарын жишээ сагс |
| `app.js` | Дэлгэц |
| `test_engine.js` | `node test_engine.js` |

Орлуулсан үнэ, баримт `localStorage`-д хадгалагдана. «Жишээ сэргээх» дарвал эх өгөгдөл буцна.
